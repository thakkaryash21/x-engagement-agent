# Operator Guide

1. Copy `example/data` to `data`.
2. Fill in `data/personas/`, `data/company-facts.md`, and `data/writing/`.
3. Start the dashboard with `python dashboard/server.py`.
4. Run `learn` before `scroll`, `compose`, or `send` so the style doc has confirmed patterns.
5. Keep one browser session and one agent session active at a time.
6. Stop immediately if X shows a challenge, suspicious-login warning, logged-out state, or unexpected UI breakage.
