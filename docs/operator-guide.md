# Operator Guide

1. Copy `example/data` to `data`.
2. Fill in `data/personas/`, `data/company-facts.md`, and `data/writing/`.
3. Install dependencies with `.\.venv\Scripts\python -m pip install -r requirements.txt` and `npm install`.
4. Build the web app with `npm run build`.
5. Start the dashboard with `.\.venv\Scripts\python dashboard/server.py`.
6. Run `learn` before `scroll`, `compose`, or `send` so the style doc has confirmed patterns.
7. Keep one browser session and one agent session active at a time.
8. Stop immediately if X shows a challenge, suspicious-login warning, logged-out state, or unexpected UI breakage.
